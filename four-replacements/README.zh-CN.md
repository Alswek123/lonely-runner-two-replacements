# 孤独跑者紧配置中可改动的项数

后续更新已补齐本稿所述的两个小规模缺口，7 人和 8 人的结果覆盖任意大小的整数速度。以下保留原稿发布时的范围。[后续证明及复算](../equality/README.zh-CN.md)

速度从 \(1,\ldots,n-1\) 开始，另有一名静止跑者作为参照。删去 \(k\) 个速度，加入 \(k\) 个不同的、至少为 \(n\) 的整数。若所有时刻中能达到的最大最小距离恰好是 \(1/n\)，称所得速度表为紧配置。

## 一般结论

证明稿给出一个项数上的空档。对充分大的 \(n\)，存在绝对常数 \(c>0\)，当 \(k\le c n/\log\log n\) 时，紧配置的每个新速度都能唯一地与一个被删速度 \(r=n-s\) 配对，写成 \(mr\)。而且区间 \(s,\ldots,ms-1\) 中的每个整数都和 \(r\) 有大于 1 的公因子。这正是 Goddyn 与 Wong 先前给出的充分条件。

这些公因子条件又迫使实际改动数至多为 \((1/\log2+o(1))\log\log n\)。两条结论合起来说明，改动数一旦超过这个缓慢增长的上限，要构成紧配置就必须一下子超过 \(c n/\log\log n\)。上一稿只能把这段空档证明到 \(c(n/\log n)^{1/3}\)。这里的 \(c\) 是绝对常数，两个公式中的常数不要求相同；正文给出了用欧拉函数明确表述的充分条件。

证明考察同一个被删速度留下的许多时间空隙，把某个新跑者在各段上能覆盖的长度相加。接着取每段靠外的一半。若新跑者恰好是原速度的倍数，它要么倍数够小，要么在这些小段上总共只能挡住很小的比例。这样就能为每个被删速度找出各自的倍数。将配对转为完整的公因子条件，用到了随包提供的上一稿定理 1。

## 恰好四处替换

| 规模 | 本稿得到的结果 |
|---|---|
| \(n=9\) | 唯一紧配置为 \(2\{1,\ldots,8\}\)。 |
| \(10\le n<148431434\) | 没有四处替换的紧配置。 |
| \(n=148431434\) | 唯一改法是将 \(n-2,n-4,n-8,n-14\) 分别翻倍。 |
| 所有 \(n\ge10\) | 四处任意替换保持紧，当且仅当可配对且四个公因子条件都通过。 |

数字 148431434 已出现在早先的极值系数计算中。这次的结论排除了插入任意大整数后在更小规模产生其他四处替换的可能。\(n=5,6\) 由已有的小维数分类直接列出，详见正文末页。

**仅有两个规模仍留有缺口。** 在 \(n=7,8\) 时，如果四个插入速度中最小的 \(M\le256\)，另外三个可以任意大，程序仍给出了完整清单。\(n=7\) 只有 \(3\{1,\ldots,6\}\)。\(n=8\) 只有 \(2\{1,\ldots,7\}\) 与 \(2\{1,2,3,4,5,7,12\}\)。若有其他解，四个插入速度必定全大于 256，最大者还必须在 \(n=7\) 时小于 \(123M\)，在 \(n=8\) 时小于 \(23M\)。整个孤独跑者猜想仍然开放。

## 复算

proof.pdf 是本次研究稿，main.tex 和 four.tex 是源文件。paired-converse.pdf 是几何配对之后引用的算术逆定理，paired_converse.py 包含该定理所需的有限算术检查。

使用 Python 3.9 或更高版本，保留默认断言。快速核查逐规模记录、质数与中国剩余定理计算、小规模速度比以及精确分数形式的覆盖积分：

    python verify.py

完整复算还需要支持 C++17 和 128 位整数的编译器。以下任选一条。编译和中间数据均放在临时目录。

    python verify.py --full
    python verify.py --full --compiler clang++
    python verify.py --full --compiler zig c++

reduce.cpp 用两条解析不等式排除删除位置。refine.cpp 同时检查多段时间上的精确覆盖比例。screen.cpp 检查四个新速度能否满足所有剩余必要条件。cover.cpp 和 circle.hpp 对剩余问题逐段计算，搜索上界由剩余空隙的长度推导。程序对 \(9\le n\le42\) 的 850612 个删除四元组做了无预筛枚举，并对上层筛法留下的另外 1284 个删除四元组做了同样的逐段检查。\(n\ge12000\) 由解析不等式统一处理。

四个文本文件分别保存筛选后保留的规模及删除位置（refined.txt）、每个规模的候选数（screen-sizes.txt）、有待逐段检查的删除四元组（ind-groups.txt）和逐规模覆盖搜索的输出（cover-sizes.txt）。完整复算会重新生成并核对这些记录。本稿尚待独立数学审阅。

原始文献见 [Goddyn 与 Wong 的定理 3.1 及其逆问题](https://www.sfu.ca/~goddyn/Papers/063tight_lonely_runner.pdf) 和 [Zhang 的多项替换问题](https://arxiv.org/html/2608.13599v3#S8)。
